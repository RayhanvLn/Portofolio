# R/F — Rayhan Fakhri Risqullah Portfolio

A motion-heavy personal portfolio built with a dark obsidian + McLaren papaya orange visual system.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP + ScrollTrigger
- Lenis smooth scroll
- Lucide icons

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Main content locations

- Personal/project data: `data/portfolio.ts`
- Hero identity and copy: `components/Hero.tsx`
- About/statistics: `components/Snapshot.tsx`
- Selected work: `components/Projects.tsx`
- Skills/capabilities: `components/Services.tsx`
- Organization + education: `components/Journey.tsx`
- Contact + CV download: `components/Footer.tsx`
- Colors/layout/motion styling: `app/globals.css`
- Project visuals: `public/projects/`
